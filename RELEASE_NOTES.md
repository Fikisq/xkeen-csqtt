# XKeen UI CSQTT 0.1.0

## Установка и обновление

Одна команда из README устанавливает панель с нуля или обновляет существующую совместимую установку. Entware должен быть включён заранее. Установщик добавляет XKeen, Xray 26.9.9, базы RoscomVPN/GeoSite, nfqws2, нативный CSQTT 2.1.9 и WDTT Plus v20.

## Исправления после проверки на роутере

- Исправлен путь к модулю информации о процессоре XKeen 2.1: Xray и панель запускаются после чистой установки.
- Исправлены права каталога: nfqws2 может читать Lua-файлы после перехода на пользователя nobody.
- В начальную конфигурацию включён HandlerService для добавления подписок через локальный API.
- После ошибки подписки окно перечитывает конфигурацию, сохраняя введённую ссылку.
- Подбор nfqws2 показывает причину ошибки запуска проверки.
- Служебные списки портов/IP и настройки XKeen скрыты из редактора конфигурации.
- При установке создаются пустые списки «Без VPN» и «Устройства Xray», поэтому привычные вкладки видны сразу.
- При обновлении старого шаблона недостающий HandlerService добавляется с резервной копией конфигурации; Xray перезапускается один раз только при необходимости.
- При обновлении сохраняются настройки и стратегии; вспомогательные скрипты nfqws2 обновляются.

VK-токен вводится в панели. Получение через VK по-прежнему требует вставить итоговую ссылку вручную. Браузер может хранить вкладки устройств после переустановки; это не восстановленные правила роутера.

Обычное обновление поверх и повторная установка с нуля этого выпуска ещё требуют проверки на рабочем роутере. Перед удалением сохраняйте резервную копию.
