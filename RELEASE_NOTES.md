# XKeen UI CSQTT v0.1.1

Стабильный выпуск для ARM64/Entware. Маршрутизация построена на Xray.

## Добавлено

- **Массовая смена выхода:** выделение нескольких правил и назначение общего outbound в общей маршрутизации и профилях устройств. Условия, порядок и состояние включения правил сохраняются.
- **Обновление панели:** окно в стиле обновления Xray — выбор стабильного или предварительного релиза, описание изменений и кнопка «Установить». Перед заменой проверяются SHA-256, архитектура и версия файла. При неудачном запуске восстанавливается предыдущая панель; настройки и дополнительные клиенты не переустанавливаются. Для нового стабильного выпуска появляется отметка NEW.
- **Отпечаток CSQTT:** выбор Firefox, Chrome, Safari, Edge или Opera; для новых установок выбран Firefox.
- **Постоянные Device ID:** новые установки CSQTT и WDTT Plus получают узнаваемый идентификатор роутера. Уже зарегистрированные ID сохраняются.
- **Журналы дополнительных клиентов:** выбор `csqtt.log`, `wdtt-plus.log` и `nfqws2.log` для установленных компонентов.
- **Контроль состояния CSQTT:** проверка HTTPS через туннель и ограниченное автоматическое восстановление при повторных сбоях. Ручная остановка учитывается. Проверки выполняются при работающей панели.

## Исправлено

- В клиенте **CSQTT 2.1.9-router.3** тайм-аут GETCONF/handshake отдельного соединения обрабатывается как локальная ошибка с повторной попыткой. Явные отказы авторизации остаются отдельными ошибками.
- Добавлена диагностика этапов подключения и понятные сообщения об отказе сервера: неверный пароль, привязка пароля к другому устройству, истёкший доступ или несовместимый протокол. Тайм-аут не выдаётся за неверный пароль.
- Статус «Туннель работает» подтверждается передачей трафика, а не только наличием процесса или интерфейса.
- Журналы дополнительных клиентов ограничены **5 МиБ**: при достижении лимита файл очищается без перезапуска клиента. Проверка размера работает при запущенной панели.
- Чекбоксы выбора правил приведены к оформлению панели. Номер версии панели оформлен так же, как версия Xray.

## Изменено

- Для Auto VK сохраняется профиль браузера и ОС, ограничены повторные запросы и обработаны паузы при ошибках VK. Серверный Device ID отделён от идентификатора VK. Эти изменения не гарантируют отсутствие капчи, ограничений или блокировки аккаунта.
- Возвращён единый формат названий выпусков: `vX.Y.Z` и `vX.Y.Z-beta.N`.
- В README уточнена команда обновления поверх существующей установки.

## Установка и обновление

Используйте одну команду из [README](https://github.com/Fikisq/xkeen-csqtt#readme). Обновление панели сохраняет настройки, подписки и правила.

Комплект включает панель, XKeen, Xray 26.9.9, nfqws2, нативный **CSQTT 2.1.9-router.3**, WDTT Plus v20 и установку баз RoscomVPN/GeoSite. Уже установленный клиент CSQTT при обычном обновлении панели автоматически не заменяется: исправления самого клиента требуют отдельного обновления его пакета.

VK-токен вводится в панели: после входа VK нужно вручную вставить итоговую ссылку, из которой панель извлечёт токен.

## Что не включено

- Экспериментальная оптимизация **CSQTT 2.1.9-router.4** отклонена после сравнения на роутере и не входит в сборку.
- Ручной настройки MTU и автоматического подбора MTU **нет**. Выполнялись только замеры; штатный MTU нативного клиента 2.1.9 остаётся **1300**.

## Пересборка v0.1.1

Выпуск пересобран с установкой версий из панели. Если установлен первоначальный v0.1.1 без кнопки «Установить», обновите его один раз командой из README. Для последующих обновлений можно использовать окно «Панель».
