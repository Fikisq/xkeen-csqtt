# v0.1.3

Стабильный выпуск для Keenetic ARM64, KeeneticOS 4+ и Entware.

- Обновлён интерфейс маршрутизации, автопереключения, резервных копий и геофайлов для Xray и Mihomo.
- Автопереключение на CSQTT / WDTT Plus при режиме белых списков с автоматическим возвратом прежних маршрутов.
- Исправлены обновление интерфейса при смене ядра, соединения Mihomo и просмотр геобаз / MRS. Раздельные геофайлы для двух ядер.
- Резервные копии включают настройки Xray, Mihomo, CSQTT и WDTT Plus; доступны выборочное восстановление и цветные метки состава.
- nfqws2: автопроверка стратегии по заданному интервалу, подбор полной рабочей замены и повторная проверка после применения.

При обновлении сохраняются пользовательские маршруты, подписки и настройки клиентов. Стартовые правила добавляются только при первой установке: direct, реклама — blocked / REJECT. Личные конфиги, токены, ключи, хеши подключений, логи и бэкапы в релиз не входят.
