# XKeen UI CSQTT

Панель для управления Xray на роутере: подписки, правила маршрутизации, отдельные устройства, nfqws2, CSQTT и WDTT Plus.

## Установка и обновление

Нужны KeeneticOS 4+ на ARM64, работающий Entware и доступ к его SSH от root.

**XKeen и Xray отдельно ставить не нужно.** Установщик сам подготовит их, установит панель, базы RoscomVPN/GeoSite, nfqws2, CSQTT и WDTT Plus. Существующие Xray/XKeen и настройки сохраняются. Entware нужно включить средствами прошивки до запуска команды.

Если уже используется другой XKeen с Mihomo или старой структурой конфигурации, **не удаляйте его**. Установщик обнаружит несовместимость и остановится с пояснением. Автоматический перенос произвольной старой установки пока не поддерживается; обычное обновление совместимой установки сохраняет её настройки.

Выполните на роутере:

```sh
opkg update && opkg install curl && mkdir -p /opt/tmp && curl -fsSL https://raw.githubusercontent.com/Fikisq/xkeen-csqtt/main/setup.sh -o /opt/tmp/xkeen-ui-setup.sh && sh /opt/tmp/xkeen-ui-setup.sh beta auto
```

Команда сама выбирает установку или обновление последнего пробного релиза. Для ручного меню:

```sh
sh /opt/tmp/xkeen-ui-setup.sh beta
```

Установщик скачивает готовый [релиз](https://github.com/Fikisq/xkeen-csqtt/releases) и проверяет контрольную сумму. Изменения в Git сами по себе не обновляют панель на роутере.

Откройте **`http://IP-роутера:1000`**, например `http://192.168.1.1:1000`.

Адрес роутера не вшит: панель работает на его IPv4-интерфейсах, а браузер использует адрес открытой страницы. Установщик показывает IPv4-адрес интерфейса `br0`; если определить его не удалось, подставьте адрес роутера вручную. Порт по умолчанию — `1000`.

## Как пользоваться

1. В **Настройках** включите авторизацию и задайте пароль. Новая установка пока направляет трафик напрямую.
2. В управлении Xray откройте **Подписки** и добавьте HTTPS-ссылку.
3. В **Маршрутизации** выберите выход и настройте правила. Изменения таблицы применяются автоматически.
4. Для отдельного устройства нажмите **Добавить IP**. Правила можно импортировать и экспортировать.

**Прямой выход** сохраняет действие правил сайтов. **Полный обход без VPN** отключает их для выбранного устройства или общей маршрутизации.

- В карточках показаны протокол и пинг, максимум три ряда. Через **Все подключения** выберите видимые карточки; там же есть поиск, автопинг и ручной пинг.
- **Диагностика** показывает DNS роутера, выход из access.log, предполагаемое правило и связанные ошибки для выбранного устройства и ресурса.
- Базы доменов и IP выбираются при редактировании правила; можно загрузить свои файлы `.dat`.
- Новые профили получают правила: реклама VK → блокировка, Нейронки, YouTube, RU → напрямую, маршрут по умолчанию. Один шаблон используется для Xray, CSQTT и WDTT Plus.
- **Журнал** расположен под таблицей: `access.log` показывает соединения, `error.log` — ошибки. При работающей панели `access.log` автоматически очищается при достижении 5 МБ; размер проверяется каждые 5 секунд.
- Кнопка остановки вверху выключает Xray, CSQTT, WDTT Plus и nfqws2 и убирает перехват трафика. Правила сохраняются; кнопка запуска возвращает ранее работавшие сервисы. Перезапуск Xray сохраняет работающие дополнительные клиенты.
- Настройки содержат тему, авторизацию, часовой пояс журнала и историю входов.
- Перед изменением конфигурации сохраните резервную копию через меню **…**.

## Дополнительные клиенты

Текущие версии: **CSQTT 2.1.9** — нативный клиент для роутера, собранный из исходников; **WDTT Plus v20**.

**CSQTT**, **WDTT Plus** и **nfqws2** устанавливаются вместе с панелью. Для CSQTT и WDTT Plus нужен собственный сервер. Если компонент удалён, его можно вернуть кнопкой **Установить** в управлении ядром; вручную копировать бинарники не нужно. Сами туннели запускаются после настройки в панели.

Установщик панели **не запрашивает токен VK**. Параметры сервера, пароль, ссылки и токен вводятся в панели. В CSQTT по умолчанию выбран **Авто ВК**, которому нужен токен; для своих готовых ссылок выберите **Ручной**. В WDTT Plus используется ручной ввод ссылок/хешей, токен он не принимает. Не публикуйте токен и ссылки подключения.

Подробности: [руководство](docs/panel-guide.ru.md). Клиенты распространяются на условиях авторов: [CSQTT](https://github.com/amurcanov/csqtt) — PolyForm Noncommercial, [WDTT Plus](https://github.com/Ivan4537/WDTT-Plus) — GPL-3.0.

## nfqws2

**Проверить стратегию** быстро проверяет выбранные параметры. **Подобрать стратегию** генерирует варианты TCP/QUIC в фоне; подбор можно отменить. Рабочие варианты сохраняются на роутере (до 16), лучший результат проверяется повторно. Активная стратегия меняется после **Сохранить и применить**. При обновлении панели обновите также пакет nfqws2, если появилась просьба обновить утилиту проверки.

В подбор включены адаптации HTTPS/QUIC из Flowseal 1.10.3 и 1.10.2. Опция **Голос Discord и игры (Roblox) · UDP** добавляет голосовые и игровые правила только к выбранному профилю nfqws2. Звонок и игру проверяйте отдельно: таблица YouTube/Discord/Instagram показывает ответы сайтов, а не работу голоса или игры.

## Обновление баз

Новая версия установщика загружает RoscomVPN GeoSite/GeoIP и обычный GeoSite для «Нейронок». Панель проверяет обновления каждые 12 часов, скачивает только изменившиеся базы и проверяет SHA-256. Работающий Xray получает изменения через API без перезапуска; при ошибке возвращаются прежние базы.

Команды на роутере:

```sh
xkeen-geodata update       # проверить сейчас
xkeen-geodata interval 12  # интервал в часах, 0 — отключить
xkeen-geodata status       # версии и последняя проверка
```

DNS интернет-трафика CSQTT задаётся сервером. Разрешение адресов VK до подключения выполняется автоматически через DNS роутера.

## Если панель не открывается

Проверьте IP роутера и порт, затем выполните:

```sh
/opt/etc/init.d/S99xkeen-ui restart
```
