# XKeen UI CSQTT

Панель для роутеров **Keenetic ARM64 с KeeneticOS 4+ и Entware**.
Маршрутизация — **Xray или Mihomo**.

## Требования

- **RAM:** от 512 МБ. 256 МБ для полного набора недостаточно.
- **Накопитель Entware (`/opt`):** рекомендуется от 256 МиБ доступного места под полный набор и обновления. Подойдёт встроенная память или USB-накопитель. Расход зависит от баз и сжатия файловой системы; 128 МБ общей flash-памяти не гарантируют достаточного места в `/opt`.

## Установка и обновление

Выполните в SSH Entware от root:

```sh
opkg update && opkg install curl && mkdir -p /opt/tmp && curl -fsSL https://raw.githubusercontent.com/Fikisq/xkeen-csqtt/main/setup.sh -o /opt/tmp/xkeen-ui-setup.sh && sh /opt/tmp/xkeen-ui-setup.sh auto
```

Для беты после скачивания скрипта:

```sh
sh /opt/tmp/xkeen-ui-setup.sh beta auto
```

Команда устанавливает панель, XKeen, Xray, nfqws2, CSQTT, WDTT Plus и базы маршрутизации. При обновлении сохраняются настройки, подписки, правила и данные клиентов. Установленные версии CSQTT и WDTT Plus автоматически не заменяются.

При новой установке стандартные правила направлены в `DIRECT`, реклама — в `blocked` (`REJECT` в Mihomo); создаются пустые журналы и начальная резервная копия настроек этого роутера. GeoSite содержит домены, GeoIP — IP-подсети; штатные базы обновляет панель (по умолчанию раз в 12 часов). Для Mihomo доступны отдельные геобазы и дополнительные MRS-наборы Discord и Telegram, которые ядро обновляет раз в сутки. Недоступность загрузки MRS не мешает основным правилам на геобазах.

Резервные копии сохраняют настройки XKeen, панели, Xray, Mihomo (включая YAML подписок), CSQTT и WDTT Plus. Для CSQTT входят конфигурация и VK-токен; для WDTT Plus — конфигурация, пароль, Device ID и дополнительные сохранённые параметры соединения. Состав отображается цветными метками, доступно выборочное восстановление. Геобазы, исполняемые файлы, логи и временные файлы в архив не входят; старые архивы совместимы. Архивы содержат секреты подключений.

Вкладка «Автопереключение» проверяет пять зарубежных HTTPS-сайтов и доступность хотя бы одного домена белого списка напрямую через WAN. Если все пять зарубежных сайтов недоступны, а хотя бы один проверочный домен белого списка отвечает два цикла подряд, панель проверяет и при необходимости запускает выбранный CSQTT / WDTT Plus, выключает общий RU, включает отдельный Whitelist → direct и переводит остальные маршруты (включая direct) на резерв. blocked и локальные/служебные правила сохраняются. Два цикла с ответами хотя бы трёх из пяти зарубежных сайтов возвращают прежние маршруты; снимок хранится приватно на роутере, ручные изменения сохраняются. Функция изначально выключена; при включении подготавливается выключенное правило Whitelist. Для Xray используется категория `whitelist` RoscomVPN GeoSite, для Mihomo — [официальный MRS Whitelist](https://github.com/hydraponique/roscomvpn-geosite/tree/release/mihomo). Проверки работают при закрытом браузере.

Обновление не устанавливает заводские маршруты поверх пользовательских и не заменяет выбранные выходы. Кнопка «Стандартные правила» Mihomo добавляет только отсутствующие правила; уже настроенные ресурсы, профили устройств и подписки сохраняются. Пользовательские геобазы не подменяются штатными загрузками.

Панель: **`http://IP-роутера:1000`**. В настройках включите авторизацию и задайте пароль.

Обновление доступно также через **Панель v… → выбрать версию → Установить**. Проверка релизов выполняется автоматически каждые **12 часов**; метка **NEW** означает новый стабильный выпуск. Автоматической установки нет.

## Возможности

- Подписки Xray, выбор серверов и обновление узлов без перезапуска Xray.
- Общие правила и профили устройств по IP; массовая смена выхода для выбранных правил.
- Выход через Xray, CSQTT, WDTT Plus, nfqws2 или напрямую; полный обход без VPN.
- CSQTT: ручные хеши или Авто ВК, получение VK-токена через панель, выбор отпечатка и контроль доступности туннеля.
- WDTT Plus (экспериментальный): настройка сервера, потоков, хешей и режима TCP/TLS.
- nfqws2: редактируемые списки стратегий, фоновый подбор TCP/QUIC и таблица ресурсов с выбором встроенных и своих сайтов, диагностикой DNS и автопроверкой по интервалу. Автопроверка использует заданный интервал: при неполном результате подбирается замена с ответами всех выбранных ресурсов по TCP и QUIC (например, 3/3 и 3/3). После применения проверяется рабочая служба; при неудаче восстанавливается прежняя стратегия. Проверка сайтов не подтверждает работу Roblox и голоса Discord.
- Базы RoscomVPN/GeoSite с автоматической проверкой обновлений, резервные копии и журналы с лимитом 5 МиБ.
- Кнопка **Консоль** подключает к Entware; кнопки управления выводят результат в терминал. Сеанс и последние 128 КиБ вывода сохраняются при закрытии окна до завершения shell или перезапуска панели. «Очистить терминал» очищает вывод без завершения сеанса.

## Управление в терминале

```sh
xkeen-manager                 # интерактивное меню
xkeen-manager status          # статус компонентов
xkeen-manager status csqtt    # статус выбранного компонента
xkeen-manager restart panel   # перезапуск панели
xkeen-manager restart csqtt   # перезапуск CSQTT
xkeen-manager log nfqws2       # журнал
xkeen-manager update          # обновление панели
```

Компоненты: `panel`, `xray`, `csqtt`, `wdtt-plus`, `nfqws2`. Действия: `start`, `stop`, `restart`.

Если панель не открывается: `/opt/etc/init.d/S99xkeen-ui restart`.
