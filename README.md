# XKeen UI CSQTT

Веб-панель для роутера с KeeneticOS, Entware и [XKeen](https://github.com/jameszeroX/XKeen). В ней можно управлять Xray и Mihomo, подписками, маршрутами устройств и дополнительными клиентами CSQTT и WDTT Plus.

## Перед установкой

- На роутере должны работать **Entware** (`/opt`) и **XKeen**. Установка панели не заменяет их установку.
- Понадобится доступ к роутеру по SSH и свободное место в разделе Entware.
- Установщику нужны `curl`, `jq` и `sha256sum`. Если чего-то нет, установите нужный пакет через `opkg`.
- CSQTT и WDTT Plus необязательны. Для них нужны совместимые клиенты и собственный сервер. Клиенты ARM64 можно скачать кнопкой **Установить** в панели; общий установщик панели не запускает их автоматически.

## Установка на KeeneticOS

Опубликован [пробный релиз для ARM64](https://github.com/Fikisq/xkeen-csqtt/releases). Подключитесь к роутеру по SSH и выполните:

```sh
mkdir -p /opt/tmp
curl -fsSL https://raw.githubusercontent.com/Fikisq/xkeen-csqtt/main/setup.sh -o /opt/tmp/xkeen-ui-setup.sh
sh /opt/tmp/xkeen-ui-setup.sh
```

В меню выберите **1 — установить**. Для обновления запустите этот же скрипт и выберите **2 — обновить**. После установки откройте `http://IP-роутера:1000` (например, `http://192.168.0.1:1000`).

Установщик скачивает **последний опубликованный релиз** из `Fikisq/xkeen-csqtt` и проверяет контрольную сумму. Текущий выпуск рассчитан на ARM64: он включает nfqws2, файлы стратегий и модуль проверки; установленные ранее настройки nfqws2 сохраняются. Сборки панели для MIPS пока недоступны. Коммит в `main` сам по себе не выпускает бинарник и не обновляет работающий роутер. Для выбора последнего пробного релиза можно использовать `sh /opt/tmp/xkeen-ui-setup.sh beta`.

> Используйте установщик **по ссылке выше**. Команда `xkeen-ui setup` может поставить другую сборку панели.

## Первые шаги

1. Откройте панель и задайте пароль в **Настройки → Авторизация**. По умолчанию вход без пароля.
2. В **Управление ядром** проверьте, какое ядро работает: Xray или Mihomo.
3. Если у вас есть подписка, добавьте её через **Подписки**. Для Xray нужна HTTPS-ссылка с доменным именем.
4. Выберите нужный выход для всего трафика или отдельного устройства в **Маршрутизации**, затем нажмите **Сохранить и применить**.

Перед сменой правил на семейном роутере сохраните резервную копию в разделе **Резервные копии**. Если выбран полный обход **Без VPN**, правила сайтов для этого устройства не применяются.

### nfqws2 · zapret2

Это прямой выход через провайдера с обработкой DPI. Он доступен в общей и выборочной маршрутизации Xray для тех сайтов и устройств, которым вы его назначите. Ограничение `192.168.0.130` относится только к старому пробному режиму.

При новой установке файлы nfqws2 доставляются на роутер, но перехват трафика автоматически не включается. Чтобы добавить его в селекторы, нажмите **Управление ядром → nfqws2 → Подключить к Xray** и подтвердите короткий перезапуск Xray. Затем выберите nfqws2 для нужных маршрутов и сохраните их. На уже настроенном роутере установщик сохраняет действующую конфигурацию и не меняет маршруты. nfqws2 не заменяет Xray или Mihomo для маршрутов, которым назначен VPN.

## Где взять токен VK для CSQTT

Токен нужен только для режимов CSQTT, которые обращаются к VK и создают звонки. Для Xray, Mihomo и обычной работы панели он не требуется. При ручном режиме можно использовать уже полученные ссылки или хеши VK.

1. Откройте [vkhost.github.io](https://vkhost.github.io/) — это **сторонний сайт**, не часть этой панели.
2. Выберите приложение, авторизуйтесь в своём аккаунте VK и подтвердите запрошенные права, если вы им доверяете.
3. После перенаправления скопируйте **только значение** после `access_token=` и до следующего `&`. Всю адресную строку вставлять не нужно.
4. В панели откройте **Управление ядром → CSQTT → Настроить** и вставьте значение в поле **VK OAuth access_token**. Сохраните настройки.

Токен даёт доступ от имени вашего аккаунта с выданными ему правами. Не публикуйте его в чате, скриншотах, отчётах и Git. Если он попал к посторонним, отзовите доступ приложения в настройках VK и получите новый токен.

## CSQTT и WDTT Plus

Эти пункты появятся в **Управлении ядром**, но для запуска нужны клиенты и сервер. Интеграция CSQTT рассчитана на клиент **2.1.9**, WDTT Plus — на клиент **v18**. Клиенты ARM64 можно установить кнопкой **Установить**. Android-приложение нельзя использовать как бинарник роутера.

Кнопка **Удалить** сначала проверяет, что соответствующий пакет уже доступен в релизе GitHub, и не удаляет компонент, который выбран в маршрутизации. После удаления **Установить** повторно скачает пакет и проверит SHA-256. Настройки сервера остаются на роутере. Если GitHub станет недоступен, повторная загрузка тоже будет недоступна. Обновление уже установленного клиента отдельной кнопкой пока не реализовано.

Пакеты ARM64 собираются из [CSQTT v2.1.9](https://github.com/amurcanov/csqtt/tree/v2.1.9) и [WDTT Plus v18](https://github.com/Ivan4537/WDTT-Plus/tree/v18) с патчами из этого репозитория. Для CSQTT действует лицензия PolyForm Noncommercial, для WDTT Plus — GPL-3.0; используйте их согласно условиям авторов.

- **CSQTT:** укажите ссылку подключения или адрес и пароль сервера, выберите режим хешей, сохраните и примените настройки. В автоматических режимах нужен сохранённый токен VK.
- **WDTT Plus:** укажите адрес сервера, пароль и заранее полученные ссылки или хеши VK. Панель сама звонки VK для WDTT Plus не создаёт.
- Если сервис не запускается, проверьте его статус в **Управлении ядром**. Настройки туннелей меняйте по одному сервису, особенно когда роутером пользуются другие люди.

## Если что-то не работает

| Ситуация | Что проверить |
| --- | --- |
| Панель не открывается | Адрес роутера и порт `1000`; запущен ли `/opt/etc/init.d/S99xkeen-ui` |
| Подписка не добавляется | HTTPS-ссылка с доменным именем и доступность её адреса с роутера |
| CSQTT или WDTT Plus остановлен | Установлен ли нужный клиент, верны ли сервер и учётные данные |
| Маршрут не действует | Нажата ли кнопка **Сохранить и применить**, нет ли для устройства полного обхода **Без VPN** |

Подробности устройства панели и сборки находятся в [Wiki проекта](https://github.com/Fikisq/xkeen-csqtt/wiki). Исходный код компонентов — в каталогах `frontend/`, `backend/` и `router/`.
