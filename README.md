# XKeen UI CSQTT

Панель для роутеров **Keenetic ARM64 с KeeneticOS 4+ и Entware**.
Маршрутизация — **Xray**.

## Требования

- **RAM:** от 512 МБ. 256 МБ для полного набора недостаточно.
- **Накопитель Entware (`/opt`):** рекомендуется от 256 МиБ доступного места под полный набор и обновления. Подойдёт встроенная память или USB-накопитель. Расход зависит от баз и сжатия файловой системы; 128 МБ общей flash-памяти не гарантируют достаточного места в `/opt`.

## Установка и обновление

Выполните в SSH Entware от root:

```sh
opkg update && opkg install curl && mkdir -p /opt/tmp && curl -fsSL https://raw.githubusercontent.com/Fikisq/xkeen-csqtt/main/setup.sh -o /opt/tmp/xkeen-ui-setup.sh && sh /opt/tmp/xkeen-ui-setup.sh auto
```

Для беты после скачивания скрипта:

```sh
sh /opt/tmp/xkeen-ui-setup.sh beta auto
```

Команда устанавливает панель, XKeen, Xray, nfqws2, CSQTT, WDTT Plus и базы маршрутизации. При обновлении сохраняются настройки, подписки, правила и данные клиентов. Установленные версии CSQTT и WDTT Plus автоматически не заменяются.

Панель: **`http://IP-роутера:1000`**. В настройках включите авторизацию и задайте пароль.

Обновление доступно также через **Панель v… → выбрать версию → Установить**. Проверка релизов выполняется автоматически каждые **12 часов**; метка **NEW** означает новый стабильный выпуск. Автоматической установки нет.

## Возможности

- Подписки Xray, выбор серверов и обновление узлов без перезапуска Xray.
- Общие правила и профили устройств по IP; массовая смена выхода для выбранных правил.
- Выход через Xray, CSQTT, WDTT Plus, nfqws2 или напрямую; полный обход без VPN.
- CSQTT: ручные хеши или Авто ВК, получение VK-токена через панель, выбор отпечатка и контроль доступности туннеля.
- WDTT Plus (экспериментальный): настройка сервера, потоков, хешей и режима TCP/TLS.
- nfqws2: редактируемые списки стратегий, фоновый подбор TCP/QUIC и таблица ресурсов с выбором встроенных и своих сайтов, диагностикой DNS и автопроверкой по интервалу. Проверка сайтов не подтверждает работу Roblox и голоса Discord.
- Базы RoscomVPN/GeoSite с автоматической проверкой обновлений, резервные копии и журналы с лимитом 5 МиБ.
- Кнопка **Консоль** подключает к Entware; кнопки управления выводят результат в терминал. Сеанс и последние 128 КиБ вывода сохраняются при закрытии окна до завершения shell или перезапуска панели. «Очистить терминал» очищает вывод без завершения сеанса.

## Управление в терминале

```sh
xkeen-manager                 # интерактивное меню
xkeen-manager status          # статус компонентов
xkeen-manager status csqtt    # статус выбранного компонента
xkeen-manager restart panel   # перезапуск панели
xkeen-manager restart csqtt   # перезапуск CSQTT
xkeen-manager log nfqws2       # журнал
xkeen-manager update          # обновление панели
```

Компоненты: `panel`, `xray`, `csqtt`, `wdtt-plus`, `nfqws2`. Действия: `start`, `stop`, `restart`.

Если панель не открывается: `/opt/etc/init.d/S99xkeen-ui restart`.
