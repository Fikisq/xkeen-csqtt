# Адаптация Flowseal для nfqws2

Источники: [Flowseal 1.10.3](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.3) и [1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2).
Преобразование сверено с `docs/manual.md` zapret2 и Lua установленного nfqws2-keenetic 1.3.1.

`convert-flowseal.py` читает исходники, не запускает Windows-файлы. Передайте ему распакованные каталоги релизов; он создаёт `router/nfqws2-flowseal.json` и `router/nfqws2-games.args`. Каталог встроен в панель и доступен без скачивания Flowseal на роутере.

## Что переносится

- Каждая ветка TCP с портом 443 становится отдельным кандидатом TLS/443. Google и общий TLS проверяются отдельно. Списки Windows, HTTP/80, произвольные игровые TCP-порты, IPv6 и изменения hosts не переносятся; область применения задаёт маршрутизация панели.
- `fake`, `multisplit`, `multidisorder`, `fakedsplit`, `hostfakesplit`, `syndata` превращаются в одноимённые Lua-вызовы. Маркеры разрезов и overlap сохраняются.
- `ts` → `tcp_ts=-600000`; `badseq` → `tcp_seq` и `tcp_ack` с исходными значениями/defaults; `md5sig` → `tcp_md5`.
- Google TLS/QUIC совпадают по SHA256 со штатными блобами. Другие исходные `.bin` встроены как HEX. `!` для динамического TLS-фейка → `reasm_data`.
- `hostfakesplit altorder=1` не поддерживается установленной Lua: такие ветки записаны в `skipped`, без подмены порядка отправки.
- SYN-вариант получает `empty,tls_client_hello`, чтобы syndata действительно увидела SYN.
- Повторы применяются к фейкам. Реальные части multisplit/multidisorder не умножаются; для них сохраняется перенос TCP timestamp option.

## Голос и игры

Отдельная опция использует параметры `general.bat` 1.10.3:

- TLS на 2053,2083,2087,2096,8443: multisplit с Google overlap.
- UDP 19294–19344,50000–50100: распознанные Discord IP Discovery/STUN, исходный ACTIVE_DISCORD_UDP, 6 повторов.
- UDP 1024–65535: только неизвестный протокол/пейлоад, исходный ACTIVE_GAME_UDP, 12 повторов, первые два исходящих пакета. Ограничение первых двух пакетов — адаптация cutoff для nfqws2, не обработка всего игрового потока.

Расширенный перехват включается только для профиля с игровой опцией: маркированный выход nfqws2 или старое явно выбранное пробное устройство. Обычный профиль сохраняет только TCP/UDP 443. Остановка удаляет обе формы правил.

Проверка сайтов использует отдельные mark 833/queue 331 и не меняет активную стратегию. Она проверяет HTTPS/QUIC, а не Discord Voice или Roblox. Реальные игровые и голосовые сеансы пока требуют проверки пользователем.
