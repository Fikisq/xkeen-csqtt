The original blockcheck2.upstream.sh is retained for source attribution and review. The panel never executes its firewall, service-stop, DNS replacement or cleanup code. enumerate.sh sources the original standard strategy modules and replaces their test callback with a bounded argument emitter. The panel tests these arguments using its isolated queue and validates all three TCP sites. IPv4 TLS and QUIC are currently supported; auto-TTL and executable Lua initialization are excluded.

Enumeration includes TTL 1–12 and up to 4096 records per family. Network attempts remain bounded: the backend samples across family/fooling-method groups and across the full enumeration of each group before selecting 180 TCP templates. Earlier prefix-only sampling (80 records per family) could exclude timestamp/sequence/MD5 variants appearing after TTL loops. Full upstream CLI behavior is still not reproduced. Fast TCP 2/3 attempts are eligible for a longer retry; confirmed entries still require TCP 3/3.
