# XKeen UI CSQTT

Веб-панель для роутера с KeeneticOS, Entware и [XKeen](https://github.com/jameszeroX/XKeen). В ней можно управлять Xray, подписками, маршрутами устройств и дополнительными клиентами CSQTT и WDTT Plus.

## Перед установкой

- На роутере должны работать **Entware** (`/opt`) и **XKeen**. Установка панели не заменяет их установку.
- Понадобится доступ к роутеру по SSH и свободное место в разделе Entware.
- Установщику нужны `curl`, `jq` и `sha256sum`. Если чего-то нет, установите нужный пакет через `opkg`.
- CSQTT и WDTT Plus необязательны. Для них нужны совместимые клиенты и собственный сервер. Клиенты ARM64 можно скачать кнопкой **Установить** в панели; общий установщик панели не запускает их автоматически.

## Установка на KeeneticOS

Опубликован [пробный релиз для ARM64](https://github.com/Fikisq/xkeen-csqtt/releases). Подключитесь к роутеру по SSH и выполните:

```sh
mkdir -p /opt/tmp
curl -fsSL https://raw.githubusercontent.com/Fikisq/xkeen-csqtt/codex/setup.sh -o /opt/tmp/xkeen-ui-setup.sh
sh /opt/tmp/xkeen-ui-setup.sh
```

В меню выберите **1 — установить**. Для обновления запустите этот же скрипт и выберите **2 — обновить**. После установки откройте `http://IP-роутера:1000` (например, `http://192.168.0.1:1000`).

Установщик скачивает **последний опубликованный релиз** из `Fikisq/xkeen-csqtt` и проверяет контрольную сумму. Текущий выпуск рассчитан на ARM64: он включает nfqws2, файлы стратегий и модуль проверки; установленные ранее настройки nfqws2 сохраняются. Сборки панели для MIPS пока недоступны. Коммит в `main` сам по себе не выпускает бинарник и не обновляет работающий роутер. Для выбора последнего пробного релиза можно использовать `sh /opt/tmp/xkeen-ui-setup.sh beta`.

> Используйте установщик **по ссылке выше**. Команда `xkeen-ui setup` может поставить другую сборку панели.

## Первые шаги

1. Откройте панель и задайте пароль в **Настройки → Авторизация**. По умолчанию вход без пароля.
2. В **Управлении ядром** проверьте, что Xray запущен.
3. Если у вас есть подписка, добавьте её через **Подписки** в управлении Xray. Нужна HTTPS-ссылка с доменным именем.
4. Выберите нужный выход для всего трафика или отдельного устройства в **Маршрутизации**. Изменения таблицы применяются автоматически; для редактирования файлов конфигурации используется **Сохранить и применить**.

### Интерфейс маршрутизации

- Карточки выходов имеют одинаковую высоту 100 px. Название занимает до двух строк, полное название доступно при наведении; пинг расположен отдельно справа. Протокол, транспорт и безопасность показаны под названием на одной высоте у всех карточек.
- **Добавить правило**, **Импорт** и **Экспорт** находятся над таблицей. Для отдельного устройства используйте **Добавить IP**.
- Журнал находится под таблицей и сразу открывает `access.log`. Для ошибок выберите `error.log`; доступны фильтр и полноэкранный просмотр.
- Настройки панели содержат тему, авторизацию, часовой пояс журнала и историю входов.
- Категории GeoSite/GeoIP отображаются с названиями баз. Связанные ветви доменов и IP правила RU · RoscomVPN показаны одной строкой, а в Xray сохраняются отдельными правилами для условия «домены или IP».

Перед сменой правил на семейном роутере сохраните резервную копию в разделе **Резервные копии**. Если выбран полный обход **Без VPN**, правила сайтов для этого устройства не применяются.

### nfqws2 · zapret2

Это прямой выход через провайдера с обработкой DPI. Он доступен в общей и выборочной маршрутизации Xray для тех сайтов и устройств, которым вы его назначите.

При новой установке файлы nfqws2 доставляются на роутер, но перехват трафика автоматически не включается. Чтобы добавить его в селекторы, нажмите **Управление ядром → nfqws2 → Подключить к Xray** и подтвердите короткий перезапуск Xray. Затем выберите nfqws2 для нужных маршрутов и сохраните их. На уже настроенном роутере установщик сохраняет действующую конфигурацию и не меняет маршруты. nfqws2 не заменяет Xray для маршрутов, которым назначен VPN.

## Токен VK для CSQTT

Токен нужен только для режимов CSQTT, которые обращаются к VK и создают звонки. Для Xray и обычной работы панели он не требуется. При ручном режиме можно использовать уже полученные ссылки или хеши VK.

В **Управление ядром → CSQTT → Настроить** нажмите **Получить токен через VK**. Откройте вход VK, подтвердите разрешения, затем скопируйте полный адрес итоговой страницы `blank.html` в помощник панели и нажмите **Использовать токен**. Панель извлечёт `access_token`; нажмите **Сохранить** в настройках CSQTT. Пароль вводится только на сайте VK. Получение токена не запускает туннель. Если токен уже есть, его можно вставить непосредственно в поле `access_token`.

Ранее здесь рекомендовался сторонний сайт vkhost. Мы убрали эту рекомендацию: он предлагает токены разных приложений, а сообщения о блокировках аккаунтов после использования таких токенов не позволяют установить точную причину блокировки. Android-клиент CSQTT получает токен через вход VK в собственном WebView; перенос того же OAuth-запроса в браузер роутера не делает его безопасным для аккаунта. Если аккаунт уже ограничили, не используйте тот же токен повторно.

Токен даёт доступ от имени вашего аккаунта с выданными ему правами. Не публикуйте его в чате, скриншотах, отчётах и Git. Если он попал к посторонним, отзовите доступ приложения в настройках VK и получите новый токен.

## Скан геофайлов и свои базы

В меню **… → Скан геофайлов** можно найти категории GeoSite/GeoIP, в которые входит домен или IP. Скан проверяет установленные базы и не меняет маршруты. Кнопка **Добавить базу** загружает свой файл Xray `.dat` до 32 МБ в выбранную вкладку. Существующие файлы не перезаписываются. После загрузки добавьте нужную категорию в ресурсы маршрута; текстовые списки, JSON и ZIP здесь не принимаются.

В Xray базы также можно загружать прямо при создании маршрута или через **Ресурсы** существующего маршрута. Выберите **Домены** или **IP-диапазоны**, нажмите **Добавить базу .dat**, затем отметьте нужные категории. Можно объединить в одном маршруте несколько категорий одного типа из разных баз. Если `geosite.dat` уже установлен, назовите свою базу, например, `runetfreedom-geosite.dat`; панель сама создаст ссылки на её категории. После выбора сохраните ресурсы и примените изменения.

При смене режима устройства между VPN и **Без VPN** или выборе для него другого VPN-узла панель сбрасывает его старые IPv4-соединения через `conntrack`, чтобы они не продолжали использовать прежний маршрут. Соединения других устройств не сбрасываются. Общий селектор меняет маршрут новых соединений; если приложение сохраняет старое соединение, переподключите сеть только на проверяемом устройстве. Установщик пытается установить `conntrack`; если его нет, панель предложит переподключить сеть изменённого устройства.

## CSQTT и WDTT Plus

Эти пункты появятся в **Управлении ядром**, но для запуска нужны клиенты и сервер. Текущие версии клиентов: **CSQTT 2.5.0** (сборка для роутера из APK) и **WDTT Plus v20**. Клиенты ARM64 можно установить кнопкой **Установить**. Сам APK на роутере не запускается: используется адаптированный клиент для ARM64.

Кнопка **Удалить** сначала проверяет, что соответствующий пакет уже доступен в релизе GitHub, и не удаляет компонент, который выбран в маршрутизации. После удаления **Установить** повторно скачает пакет и проверит SHA-256. Настройки сервера остаются на роутере. Если GitHub станет недоступен, повторная загрузка тоже будет недоступна. Обновление уже установленного клиента отдельной кнопкой пока не реализовано.

CSQTT 2.5.0 собран для роутера из APK с адаптацией под ARM64; WDTT Plus обновлён до v20. Проекты авторов: [CSQTT](https://github.com/amurcanov/csqtt) и [WDTT Plus](https://github.com/Ivan4537/WDTT-Plus). Для CSQTT действует лицензия PolyForm Noncommercial, для WDTT Plus — GPL-3.0; используйте их согласно условиям авторов.

- **CSQTT:** укажите ссылку подключения или адрес и пароль сервера, выберите режим хешей, сохраните и примените настройки. В автоматических режимах нужен сохранённый токен VK.
- **WDTT Plus:** укажите адрес сервера, пароль и заранее полученные ссылки или хеши VK. Панель сама звонки VK для WDTT Plus не создаёт.
- Если сервис не запускается, проверьте его статус в **Управлении ядром**. Настройки туннелей меняйте по одному сервису, особенно когда роутером пользуются другие люди.

## Если что-то не работает

| Ситуация | Что проверить |
| --- | --- |
| Панель не открывается | Адрес роутера и порт `1000`; запущен ли `/opt/etc/init.d/S99xkeen-ui` |
| Подписка не добавляется | HTTPS-ссылка с доменным именем и доступность её адреса с роутера |
| CSQTT или WDTT Plus остановлен | Установлен ли нужный клиент, верны ли сервер и учётные данные |
| Маршрут не действует | Завершилось ли автоматическое применение, нет ли для устройства полного обхода **Без VPN** |

Подробности устройства панели и сборки находятся в [Wiki проекта](https://github.com/Fikisq/xkeen-csqtt/wiki). Исходный код компонентов — в каталогах `frontend/`, `backend/` и `router/`.

### Прямой маршрут и полный обход

«Маршрут по умолчанию → Без VPN» направляет остальной трафик напрямую, а отдельные ресурсы можно направлять через VPN. «Полный обход» отключает правила ресурсов и перехват трафика устройства. Это доступно в общей и выборочной маршрутизации. Существующие профили полного обхода сохраняют прежнее поведение до явного изменения.

## Базы и шаблон маршрутизации

Новый установщик загружает `roscomvpn-geosite.dat`, `roscomvpn-geoip.dat` и `geosite.dat`. Последняя — GeoSite из Loyalsoldier/v2ray-rules-dat, основанная на списках V2Fly; она нужна для OpenAI, Anthropic и Perplexity. Не заменяйте её базой RoscomVPN: наборы категорий различаются.

Панель проверяет все три источника раз в 12 часов. Интервал можно изменить командой `xkeen-geodata interval 6`, запросить проверку — `xkeen-geodata update`, посмотреть версии — `xkeen-geodata status`. Значение 0 отключает автоматическую проверку. Планировщик работает вместе с панелью, поэтому отдельные cron и фоновые оболочки не нужны.

Перед заменой проверяются SHA-256 и формат DAT. Файлы заменяются атомарно, правила работающего Xray перечитываются через API с текущими тегами подписок. При ошибке возвращаются прежние файлы и правила. Одновременно выполняется только одна проверка. При недоступности источника базы сохраняются, повторная попытка выполняется через 15 минут.

Шаблон новых профилей: Реклама VK (RoscomVPN `category-ads`) → block; Нейронки и YouTube → выбранный выход; RU (домены и IP) → direct; остальное → маршрут по умолчанию. Домены и IP RU остаются двумя правилами Xray, чтобы работало условие «или». Шаблон одинаков для Xray, CSQTT и WDTT Plus. Полный обход сохраняет своё действие и отключает правила ресурсов, включая блокировку рекламы.

В CSQTT выбор DNS убран: адреса VK/сервера до туннеля разрешаются через DNS роутера, а DNS интернет-трафика определяется сервером CSQTT. Получение DNS от сервера и его применение к туннелю сохранены.
